# ADR-0009：可导入的完整 V1 接口设计稿

- 日期：2026-10-15（Asia/Shanghai）
- 状态：用户授权补齐完整接口规划；文档与结构检查完成
- 范围：完整 V1 OpenAPI 设计稿、生成与校验脚本、Apifox 使用说明

此前的 Apifox 文件来自运行中应用，所以只包含已实现接口。用户希望开发前能在工具中看到后续业务全貌。本轮将已有 Markdown 契约转换成完整规划文件，保留独立的运行快照，用明确名称与状态区分用途。

设计稿共 61 个操作：7 个已实现，54 个待开发；按 9 个业务分组组织，补充参数、请求示例、响应结构、权限、错误、幂等键、PDF 上传和下载。已实现部分复制运行快照，不手工重写。待开发操作与新结构均为设计讨论稿，引用已有基线，不将导入视为业务批准。

通过标题前缀、x-implementation-status、x-decision-status 及 Apifox designing / tested 状态提示实际进度。tested 仅表达本机已经验证，不使用 released，避免暗示公开发布。保留浏览器只收录已实现操作的行为，不增加伪 Controller、Mock 或绕过鉴权的入口。

生成脚本检查契约覆盖、唯一 ID、路径参数、模型引用与文件新鲜度；另通过官方 OpenAPI JSON Schema 和示例结构检查。本轮仅改文档与文档工具，不重复业务构建或数据库测试。下一步先由用户查看完整规划与现有接口，再定稿商家规则并逐项实现。

导入说明和验证边界见 [完整接口规划](../api-design.md)。
