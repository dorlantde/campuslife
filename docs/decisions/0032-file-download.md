# ADR-0032：本人PDF受控下载与清理协调

- 日期：2026-10-23。
- 状态：用户明确“采用并实现”；实际验证见[下载验收](../file-download.md)。
- 方案：[本人PDF受控下载](../file-download-design.md)。

## 决定与理由

新增GET /api/v1/files/{fileId}/content，仅正常STUDENT本人及有效会话。提供带Bearer的原文件附件下载，便于学生确认文件内容，也补齐后续打印流程的受控内容读取基础。商家必须依赖实际打印订单的授权尚未接入，不能凭角色读取学生文件；ADMIN没有默认内容权限。

沿用规范正BIGINT ID、先归属后生命周期、等于expiresAt即过期。不存在/他人/UPLOADING统一404，本人到期/DELETING/DELETED为410；有效记录但当前存储根不匹配、对象不存在、长度不符、不可读或路径不安全为503，不自动改状态或伪装为过期。下载不续期，不生成订单事件或资金，不改变文件版本。

成功200为原PDF，不包装JSON。返回application/pdf、实际约定长度、安全ASCII回退名及UTF-8编码附件名、no-store、nosniff；不返回存储位置或公共URL。V1只做完整文件，Range/条件头仍返回完整200，无206/304或断点续传。使用有界缓冲，不整文件装入内存，不在每次下载重新解析PDF或预计算完整哈希；私有磁盘被外部篡改的审计/修复不属于本轮。

## 身份时点与一致性

先在只读RR中核对当前账号/会话和归属，定位内部key；在事务外取得现有文件互斥后，使用新的短只读RR快照复核当前账号、会话、文件及一次Clock期限。使用普通一致性读，不持有业务行锁等待互斥、磁盘或客户端。互斥等待期间的退出、停用、角色变化、期限到达或删除状态必须被复核拒绝。

授权边界是取得互斥后的该次复核；快照建立后提交的退出/停用/到期不主动中断本次已获准传输，后续请求重新验证。这避免把逐字节撤销承诺引入当前单机方案，也不能收回用户已保存的本地副本。

事务结束后核对存储根、固定随机key、非链接普通文件及已打开句柄的长度，再流式读取。整个传输及关闭在同一线程持有现有按key映射的有界互斥；正常结束或失败均finally释放。清理tryLock遇到传输跳过，不先标DELETING；释放后后续扫描恢复。清理先提交DELETING则下载拒绝。慢客户端可能延后物理清理，相同互斥桶的请求可能串行；不增加读租约、分布式锁或吞吐承诺。

写流前失败保持统一JSON；尚未提交的PDF响应缓冲及附件头可清除后返回503。已提交传输发生IO失败仅记录文件ID/追踪标识并结束，不交给JSON异常处理器追加内容。输入句柄、互斥均必须回收；不记录正文、凭证或磁盘路径。

复用file模块、V11和20张业务表，无新依赖/迁移；新增FileDownloadService，生产Java文件167→168。打印订单引用、文件保留7天及商家按订单访问仍需对应任务实现。
