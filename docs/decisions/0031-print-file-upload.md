# ADR-0031：私有PDF上传、本人元数据与未下单清理

- 日期：2026-10-23。
- 状态：用户明确“采用并实现”。规则见[确认方案](../print-file-upload-design.md)，交付与实际验证见[点击验收](../print-file-upload.md)。

## 决定与理由

新增POST /files、GET /files/{fileId}（完整前缀/api/v1），仅正常STUDENT及有效会话。服务端校验单一file、文件名末段、PDF签名/页树、实际大小/页数/哈希；20 MiB等于允许、1～500页，所有加密文档拒绝，两个上传处理槽满429。重复上传独立文件，无跨用户去重和上传幂等键。

先用本机私有目录与PDFBox 3.0.8，替代未定稿的SeaweedFS/S3候选，降低当前单机开发的运维负担。默认`.local/files/`独立于构建和缓存、Git忽略；随机key不使用客户端路径，存储根标识持久化。应用仅支持该目录单实例使用；将来S3迁移需要处理实际文件及元数据，不提前增加多后端框架。

FileView只有id、原名、字节数、mediaType、pageCount、status、expiresAt。成功AVAILABLE发布起24小时有效，等于截止即过期；本人到期/删除中/已删除410，他人/不存在/内部UPLOADING统一404，先归属后生命周期，不返回路径/key/哈希/链接。GET不续期或清理。下载、商家访问、报价与打印订单后续开发；无订单阶段不宣称实现未终结引用及终结后7天保护。

## 一致性与恢复

V11只建file_asset，20张业务表；存储位置/哈希/页数/大小/状态/版本由真实约束保护。内部UPLOADING记录目标key及30分钟发布期限：解析/文件IO在事务外，短RC事务账号→会话→文件复核后创建占位，再移动文件、复核并发布。处理时退出、停用或到期不能发布；失败只补偿未发布占位，不删除已提交AVAILABLE事实。响应丢失不等于业务事务失败；重复上传仍是新文件。

同一文件的发布与清理由实例内有界互斥协调。清理启动及每60秒扫描，最多100条，按文件独立短事务：当前读标记DELETING并提交→事务外删除→标记DELETED；失败保留重试，对象不存在视为成功，重试更新时间避免失败记录长期占满批次。清理仅匹配当前存储根标识，不能反向锁账号或未来订单。

临时文件本请求finally回收；30分钟以上非活动业务临时文件由扫描回收，启动时回收容器/PDFBox生成的遗留临时文件。仅限定目录和随机命名，拒绝路径越界及链接/重解析点，不能递归清空存储根；原内容不进入数据库/日志/仓库。数据库和目录须共同备份，JAR不包含上传文件。

实施沿用业务模块内分层、MyBatis-Plus与注解SQL，无XML、Redis、MQ或第三方存储服务。当前51个运行操作、完整62/51/11；尚未开放的打印订单必须先接入文件锁、未终结保护和所有引用终结后的7天重算。实际验证及限制见验收指南。
