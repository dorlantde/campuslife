# ADR-0038：商家按本店打印任务受控下载PDF

- 日期：2026-10-25。
- 状态：用户明确“采用并实现”；完整规则见[确认方案](../merchant-print-download-design.md)，点击与实际验证见[验收指南](../merchant-print-download.md)。

## 决定与取舍

扩展既有GET /files/{fileId}/content支持MERCHANT，不新增路径、orderId参数、表、迁移、依赖或生产Java文件。运行54、完整规划62/54/8，V1～V12、21张表、184个生产Java文件保持。复用二进制流传输和清理互斥，文件模块在既有引用Mapper内读取订单授权，不调用打印写事务。

正常商家/有效会话及本店ACTIVE OWNER，且本店至少一笔PRINT关联满足ACCEPTED/PAID/QUEUED、acceptedAt非空、startedAt/readyAt/pickedUpAt为空，文件属于订单学生，才能下载。按fileId和服务器店铺关系查是否有合格关联，不接受客户端指定店铺或学生，不维护授权副本。IN_SERVICE等未来履约状态本轮不授权，需随对应任务接入。

先接单才开放学生内容，内容不适合履约可走已有商家取消。暂停/停业、服务价目失效、学生停用或原30分钟期限经过不撤销合法旧任务授权；无合格关联404，文件7天保留期不授予商家内容权。取消一单后仍有本店另一合格单则仍允许，只有其他店的合格引用则拒绝。ADMIN无默认内容权，商家上传和本人元数据入口仍受原STUDENT限制。

## 校验与响应

首查和互斥后的复查均为短只读RR，重新读当前账号/会话/角色、OWNER、本店有效关联及文件；同一快照固定资格和任务。等待期间角色变化不在原请求中切换权限分支，403；新请求按当前角色重新校验。无店404、无效成员403、无授权文件404，先授权后查生命周期和对象，不以磁盘错误泄露他人内容。

商家合格任务的文件应AVAILABLE/expiresAt=NULL，异常503 FILE_STORAGE_UNAVAILABLE；归属不一致不授予权限。学生本人原404/410和等于到期边界保持。安全存储检查继续验证根标识、随机key、非链接普通文件及长度，异常503、不改元数据或资金；数据库暂时竞争503 SERVICE_TEMPORARILY_UNAVAILABLE，可重试原下载。

成功200原PDF附件、安全ASCII回退/UTF-8文件名、实际长度、no-store/nosniff；不返回存储位置或公共链接，不包装JSON。完整200，Range/条件头不启用206/304。不重新解析或整文件加载，不续期、不改文件/订单版本、打印进度、事件或资金，不受模拟资金开关限制。

## 并发授权与清理

先短RR定位，事务结束后等待原按key有界互斥，再新RR完整复核；比较两次定位的key/存储根，拒绝复用等待前许可。授权边界是互斥后新RR快照：快照建立前已提交的退出/停用/最后有效任务取消必须拒绝；快照后提交的取消/停用不打断已获准传输，后续请求重新判断，已保存副本不能收回。

普通一致性读，不取业务行锁，不在数据库事务内等待互斥、磁盘或客户端，也不反向锁学生。商家取消沿原元数据事务，可在下载中提交退款、关闭和期限。传输持有实例互斥，清理tryLock跳过活动文件；传输结束或失败释放后，清理按真实期限重试。维持本地单实例限制，不引入读租约或分布式协调。

写流前错误JSON，已提交PDF中断沿原协议终止连接，不追加JSON；所有路径关闭句柄并释放互斥。日志不写正文、凭证或磁盘位置。本人学生下载与已有订单/文件保护保持原规则，实际回归范围见指南。
