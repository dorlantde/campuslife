# ADR-0046：管理员账号状态、会话撤销与变更记录

- 日期：2026-10-26；状态：用户明确“采用并实现”。[确认方案](../admin-account-status-design.md)，[人工验收与实际验证](../admin-account-status.md)。

新增PATCH /api/v1/admin/accounts/{accountId}/status，仅锁后当前ACTIVE/ADMIN及有效会话，管理其他三类业务账号；严格status（ACTIVE/DISABLED）与expectedVersion（规范非负BIGINT字符串），规范正BIGINT目标ID。禁止修改本人含同状态请求409 ADMIN_SELF_MODIFICATION_FORBIDDEN；目标不存在404，版本不符或实际改变无法递增409 CONFIG_VERSION_CONFLICT。版本匹配且状态一致200不写，MAX版本也允许；旧版本重试仍409，刷新列表确认。

写RC按ID升序逐条主键锁两个账号，去重，再锁操作者当前会话并复核，全部账号锁先于任何会话锁。返回锁后投影，不加载密码摘要；原本人账号→会话→业务资源的路径保持，本入口不取店铺/日期/文件资源锁。自操作禁止且操作者保持ACTIVE/ADMIN并持锁至提交，保证每次停用另一个管理员后至少保留操作者，无需COUNT或新增全局锁；互停后失效的操作者不能继续写入。直接SQL绕过协议不属保证范围。

实际变化：目标状态/version+1、撤销目标所有未撤销会话（含过期记录）、追加一次状态历史同事务。撤销0条合法，时间沿既有GREATEST(created_at,now)保护，记录锁后UTC毫秒时刻；写后再校验操作者会话期限，异常全回滚。恢复同样撤销旧会话，不自动登录或复活旧token；登录持同一账号锁，按前后提交顺序决定旧会话被撤销或建立新的合法会话。

V15新增account_status_change：actor/target账号FK、前后状态/版本、changed_at；actor≠target、状态合法且不同、非负版本相差1，唯一(target_account_id,to_version)。只追加实际变化，不为无变化/失败写记录，不虚构旧账号状态历史，不把改昵称/密码造成的版本跳号当作丢失。无原因字段或历史查询HTTP接口，仍复用AccountView返回六字段。

不自动取消/退款订单、不释放预约占用、不改文件期限/店铺/成员/服务或评价。停用经营账号后新资格读取隐藏公开店铺、拒绝新下单/首次付款；旧单可由正常ADMIN按已有范围核实，资金开关保持。恢复仍依原经营资格，不自动获批/激活。作者停用不隐藏VISIBLE评价。旧RR快照、已获准传输及其他账号已完成资格复核的在途操作沿各模块原时点，不新增全局中断机制。

运行61→62，完整62/62/0，V1～V15/23表；沿admin模块扩展，不提供公开管理员注册、改角色、删除、重置密码或批量操作。真实MySQL排序锁/互停/回滚、登录与资料竞争、存量业务和迁移验证以指南记录为准，不以mock替代锁证明。
