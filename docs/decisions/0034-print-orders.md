# ADR-0034：打印待支付订单与全部文件引用保护

- 日期：2026-10-24。
- 状态：用户明确“采用并实现”；精确规则见[确认方案](../print-order-design.md)，操作与执行记录见[验收指南](../print-orders.md)。

## 决定及取舍

新增POST /api/v1/orders/prints，并扩展学生本人详情、取消、列表和事件支持PRINT。V12新增print_detail，沿用订单主表、事件及操作隔离的幂等表；打印流程使用独立PrintOrderService/Transactions，文件模块统一重算保护期限。不引入XML、引用计数副本、Redis或消息队列。

报价允许停业估价，创建则要求当前上海营业开关及当天区间[start,end)均满足，以免把估价误当接单承诺。不引入打印容量、预计取件时间或预约起点网格。正常学生及有效会话使用本人有效PDF，下架服务409 SERVICE_UNAVAILABLE，规格缺失/停用409 PRINT_SPEC_UNAVAILABLE；按实际页数与当前价目复算，版本或金额不符409 QUOTE_CHANGED。严格整数金额最高5000000000分，BOOKING原上限不变。

冻结店铺/服务/文件名称、规格、页数、份数、纸张数、价目ID/版本和单价；以后改名、停用或文件删除不改变历史。PRINT详情booking=null，printing为明确对象；学生列表默认两类、可筛选，PRINT预约日期null。GET只读RR不自动关单或续期；商家列表仍只开放BOOKING。打印支付、商家内容读取和履约、管理员打印操作本轮均未开放。

## 原子性与锁

创建必须原子提交主订单、打印扩展、CREATE事件、CREATE_PRINT幂等事实及文件NULL保护。锁后取毫秒时间，15分钟待支付，提交前重新检查会话。Idempotency-Key格式沿用原规则，命名空间(account,CREATE_PRINT,key)；预约仍CREATE_BOOKING，二者互不占键。摘要包含所有归一化输入和价格预期。同摘要重放原单当前状态，不校验旧磁盘或营业资格，不改期限；异摘要409。唯一键失败先回滚再新事务查原结果，死锁/锁等待失败503并保留原键重试。

新创建先短事务检查身份/已存在键，再在任何数据库事务外等待现有实例文件互斥。持有互斥后重查已完成键和本人文件，事务外打开安全普通对象核对根标识/长度并关闭。随后RC事务按学生账号X→会话X→店铺S→文件X→订单/扩展→事件/幂等写入，锁内复核当前资格、文件和价格。互斥直到事务提交才释放，绝不持有数据库锁后等待文件互斥。

重放也沿账号→会话→店铺S→文件X→原订单协调，以免主状态与打印进度混读；不访问磁盘或获取实例互斥。取消和扫描仅元数据操作，不获取实例互斥或执行IO；系统扫描沿店铺S→文件X→订单，不反向锁学生或经营账号。配置仍店铺X入口。

## 文件保护与终结

print_detail.file_id就是引用事实，file_asset行X序列化所有创建和终态写入。任一PRINT非CLOSED/COMPLETED，expiresAt=NULL；全部终结，最晚closedAt/completedAt+7天。本轮未支付取消和超时也保留7天。其他关联订单使用RC普通读，不跨店铺取订单锁。仅期限实际变化才递增文件版本；写入上限失败必须整笔回滚。

保留期内新订单可重新保护，过期/DELETING/DELETED不能复活。清理持有同一实例互斥和文件行锁，标记删除前额外确认无未终结引用；矛盾只记录文件ID并跳过，不误删或擅改事实。原文件元数据保留，订单冻结历史仍可读取。仍受本地单实例部署限制。

学生严格早于截止取消为USER_CANCEL；达到截止先提交PAYMENT_TIMEOUT、ABORTED、事件和引用重算，事务外再409 PAYMENT_DEADLINE_PASSED。重复USER_CANCEL成功、重复超时409，均不重写时间/事件或续期。PRINT超时独立启动首扫/30秒/每批100条、逐单事务，不挤占BOOKING两个既有扫描配额；停用学生或暂停店铺不阻止清理旧单。无资金写入，不依赖模拟资金开关。
