# ADR-0035：打印模拟支付与待接单全额退款

- 日期：2026-10-24。
- 状态：用户明确“采用并实现”；精确规则见[确认方案](../print-payment-design.md)，操作与验证见[打印支付指南](../print-payments.md)。

## 决定与理由

扩展既有POST /orders/{orderId}/payments/mock支持PRINT，学生本人取消、详情、列表/事件及创建重放同步读取真实支付/退款事实；打印扫描增加独立待接单100条配额。运行路径仍54、完整规划62/54/8，无新迁移、表或依赖。复用V10唯一成功支付/全额退款事实及V12打印明细，打印事务保持独立服务，预约业务行为沿原ADR。

首次付款只接受正常学生本人、有效会话及PENDING_PAYMENT/NOT_PAID/QUEUED，锁后now严格早于15分钟截止；店铺仍具公开PRINT经营资格。下单后停业、营业结束、服务或规格停用、改价不阻止旧单按冻结金额付款，不重新报价或重新要求当前营业。金额全程long，最大50亿分不截断。

首次付款复核关联文件仍本人AVAILABLE且expiresAt=NULL，元数据不变量异常503 FILE_STORAGE_UNAVAILABLE并回滚。付款不重新打开/解析PDF、不等待实例文件互斥；创建已验证对象，正常清理受全部引用保护。取舍是付款本身不能探测外部损坏/删除，下载及未来履约读取才检查实际对象；不以付款宣称已经再次检查磁盘。

## 资金、期限与重放

支付成功原子写唯一MOCK/SUCCEEDED支付事实、PENDING_ACCEPTANCE/PAID、paidAt和paidAt+30分钟acceptanceDeadline、版本+1与PAYMENT事件。打印继续QUEUED、文件NULL保护不改版本，不伪造商家确认。统一锁后时刻固定，后续SQL耗时不移动paidAt；提交前会话失效全部回滚。

重复合法支付200原事实/当前状态，不改时间/版本/事件，即使已超过接单期限但尚未退款也不自动退款。重放先身份/归属，绕过首次付款的经营资格/文件元数据/资金开关。已退款或USER_CANCEL关闭409 ORDER_STATE_CONFLICT，PAYMENT_TIMEOUT关闭409 PAYMENT_DEADLINE_PASSED。资金按订单唯一，不增加付款创建键。

待接单学生取消全额模拟退款，USER_CANCEL；达到接单期限则ACCEPTANCE_TIMEOUT，退款关闭提交后外层409 ACCEPTANCE_DEADLINE_PASSED。保留原成功支付记录，插入唯一全额成功退款；CLOSED/REFUNDED/ABORTED、closedAt、版本、原关闭事件及全部引用期限同事务。退款不要求店铺仍公开/营业或磁盘存在，系统也能处理停用学生的旧单。PRINT已接单及后续学生取消仍拒绝。

重复USER_CANCEL返回原关闭/退款，重复超时取消仍期限409，均不重写事实或续期；仅一次关闭事件，不另合成REFUND事件。详情展示原成功payment与成功refund，列表显示真实主状态及QUEUED/ABORTED，GET与创建重放均不触发资金操作。

## 锁、文件及恢复

写RC：学生账号X→会话X→店铺S→文件X→订单X→打印明细X→流水/事件；系统无账号/会话，仍店铺S→文件X→订单/明细。锁后重新读取主/扩展状态，不反向锁经营账号或跨店其他订单。所有支付/取消/扫描共用打印锁入口；文件引用终态重算仍由file模块负责。

写操作返回和创建重放使用订单/打印明细锁查询构造视图，不再次复用定位用的普通selectById；MyBatis事务内一级缓存可能保留等锁前结果，RC隔离本身不会清空这份应用缓存。只读RR详情仍使用原普通查询，保持一个快照。

任一关联PRINT未终结则expiresAt=NULL，全部终结按最晚实际closedAt/completedAt+7天；支付不续期，退款不立即删文件。必要期限变更遇文件版本上限必须连同资金/状态/事件回滚；其他引用仍未终结、期限不变时不无意义递增。磁盘IO不进入资金事务，文件清理防护不变。

所有新支付和退款受现有模拟开关保护，默认关闭，本机开发显式启用；不修改本机凭据。关闭时已有成功事实可重放，未付款取消/超时继续；已付到期保持PAID及文件NULL保护并记录提示。恢复启用后按原截止处理，实际关闭后才开始7天。

打印扫描启动首扫、每30秒，两组未支付/待接单分别最多100条、每单独立事务，某单失败或退款关闭不能阻止未付组。预约两个既有配额不变；不在打印创建或GET内清理其他订单。SQL竞争整笔回滚503，唯一约束保证至多一笔资金事实，不能替代状态校验。

## 阶段边界

本轮未开放打印商家列表/详情/事件/接拒单、内容访问、打印履约/取件及管理员打印异常。付款后仍须等待商家，当前可由学生取消或30分钟后自动退款。下一项应独立定稿商家打印确认及存量权限，不因已有资金或打印枚举推断履约已开放。
