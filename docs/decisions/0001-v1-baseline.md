# ADR-0001：V1 业务基线与设计边界

- 日期：2026-10-12（Asia/Shanghai）
- 状态：业务基线及两项异常退款规则已确认；其余数据库细节与边界待审阅
- 背景：用户确认第一轮设计，并授权开始细化 V1 数据库与状态迁移表。
- 本轮产物：设计文档。没有应用代码、DDL 执行或测试结果。

## 已确认的业务基线

| 项目 | 决策 |
|---|---|
| 场景 | 星海大学，一个校区，V1 仅理发和打印两种交易 |
| 架构 | 模块化单体；先不拆微服务 |
| 订单 | 通用主表 + 按类型划分的扩展表；一单一项服务 |
| 预约流程 | 创建暂占 → 模拟支付 → 商家确认 → 到店服务 → 完成 |
| 预约范围 | 未来 7 天，开始时间按 15 分钟对齐，不跨午夜，至少提前 2 小时 |
| 支付期限 | 下单后 15 分钟 |
| 接单期限 | 支付后 30 分钟；未确认则关闭并全额模拟退款 |
| 学生取消 | 待支付、待确认可取消；已确认理发预约距开始至少 1 小时可取消；打印接单后不直接取消 |
| 商家取消 | 待接单可拒单；接单后、服务开始前可因无法履约取消并全额模拟退款 |
| 完成 | 理发由商家完成；打印进入待取件后由学生确认完成 |
| 打印文件 | V1 仅 PDF，单文件单订单，最大 20 MB；完成或关闭后保留 7 天；未绑定订单的上传文件 24 小时清理 |
| 定价 | 服务端报价；整数分；保存服务、价格和规格快照 |
| 身份 | V1 账号单角色，一个商家账号管理一家店；用店铺成员关系表达归属 |
| 优惠券 | V2 店铺满减券、一单一券；已支付订单退款后默认不返券 |
| 扩展 | 交易场景复用订单公共能力并增加业务扩展；信息查询场景进入设施模块 |

“单文件单订单”指每笔打印订单只有一个文件，不限制学生以同一个有效文件创建多笔订单。文件清理必须检查所有关联订单。

## 架构取舍

统一主表避免重复实现支付、归属查询、关闭和评价；扩展表避免大量空字段。主表不包含理发时间或打印规格，不以 JSON 承载核心可查询字段。

新增业务仍然需要类型、接口和履约规则，不承诺零修改扩展。仅当新增业务确实复用公共生命周期时接入订单体系。

预约并发采用“理发师 + 日期”保护行作为默认方案。所有影响当天排班和占用的写入都遵守此协议。它牺牲同一理发师同一天的写并发，换取明确的正确性边界；V3 再比较固定时间格等方案。

基础并发正确性、超时关闭与文件权限属于 V1。Redis、MQ、可靠异步退款和复杂售后不作为 V1 的正确性前提。

## 本轮细化的建议，尚未单独定稿

2026-10-13 用户明确确认：预约结束仍未到店、服务开始后发生异常，V1 均由管理员核实后全额模拟退款并关闭订单。核实记录须包含操作人和原因；不自动认定缺席责任，不自动扣款。开始前关闭释放占用，开始后关闭保留已使用区间。部分退款和完整争议审批留到 V2。

以下其他细化建议仍保留讨论稿性质：

| 细节 | 建议及理由 |
|---|---|
| 预约“未来 7 天” | 按校园本地日期计算，含当天至第 6 天；当天仍受提前 2 小时限制 |
| 支付边界 | 当前时间必须严格早于支付截止时间；等于截止时间即不可支付 |
| 接单边界 | 当前时间严格早于接单截止时间；等于截止时间即不可接单 |
| 理发到店开始 | 商家仅能在预约开始至结束时间之间标记开始；暂不提供提前开始和超时开始 |
| 待取件 | 不自动完成，不因文件到期清理而丢失待履约文件 |
| 报价变动 | 下单时重新报价；客户端携带报价版本与预期金额，不一致返回报价已变化，要求重新确认 |
| 理发提前完成 | 可以完成，但不重新开放原预约区间 |
| 修改排班 | 不允许修改为与现有占用不兼容的排班；必须先处理相关预约 |
| 账号停用 | 禁止登录及写操作，不批量删除订单；管理员负责存量履约异常 |

这些边界涉及正常流程之外的业务判断，工程实现前要共同审阅，不能仅凭字段已经存在就视为业务已经实现。

## 技术选型状态

候选为 Java 21、Spring Boot 4.1.1、MyBatis-Plus 3.5.17 的 Boot 4 starter、springdoc-openapi 3.1.1、MySQL 8.4 LTS。框架管理的依赖随 Boot BOM；独立组件在初始化时固定具体版本。

2026-10-13 更新：Java 21 + Spring Boot 4.1.1 已用于最小工程并通过构建、Web 测试和 jar 启动验证，见 [ADR-0002](0002-engineering-foundation.md)。其他数据库、安全及文档组件仍在对应模块引入时验证。

当前机器检测到 Java 24.0.1、Maven 3.9.16。本轮不切换 JDK 或安装依赖。
