# ADR-0016：商家打印规格价目

- 日期：2026-10-20（Asia/Shanghai）。
- 状态：用户在 [价目提案](../merchant-print-prices-design.md) 后明确选择“采用并实现”。
- 范围：GET /merchant/services/{serviceId}/print-prices、PUT 同一路径，以及 V6 迁移。文件、学生报价、订单另行推进。

经营资格沿用 ACTIVE / MERCHANT、APPROVED 店铺、本人 ACTIVE OWNER；服务必须为本店 PRINT。店铺手动停业、无营业时间或服务下架不妨碍价目维护。本店 HAIRCUT 返回 400，不存在或非本店服务统一 404。

V1 仅 A4，支持 BW / COLOR × SINGLE / DOUBLE 四种规格。每项单价为严格 JSON 整数分/印刷面 1～100000；enabled 必须显式布尔值。按印刷面计价，双面不自动半价；未来最终金额使用命中且启用的价目，不能使用服务参考起价兜底。本接口不自动改写参考起价。

PUT 每批 1～4 条不同规格，所有字段必填，未知字段拒绝。新规格 expectedVersion 必须显式 null，已有规格传该价目版本字符串；遗漏规格保留，空批次拒绝。先检查整批，再执行必要写入，任何失败整批回滚。每条规则版本独立，实际变化才递增，无变化仍检查权限和版本；版本上限仅允许无变化。不递增店铺/服务版本，不删除或重建已有规格身份。重复创建/旧版本更新不提供自动成功回放。

查询返回完整数组，含停用规格，未配置为 []，顺序固定 BW/SINGLE、BW/DOUBLE、COLOR/SINGLE、COLOR/DOUBLE。PUT 返回保存后的同样完整数组，包含本次遗漏的已有规格。

V6 新建 print_price_rule，保留 service_id 外键、规格唯一键、金额/枚举/布尔/版本 CHECK。调整原数据库讨论稿：不重复保存 shop_id，通过不可变的服务归属确定店铺，避免双归属字段不一致。沿用 MyBatis-Plus、注解 SQL 与 merchant 分层，无新增依赖。

写锁顺序为本人账号 → 当前会话 → 店铺 → 本人 OWNER → 服务 → 固定顺序的价目规则。服务父行协调尚不存在的规格，不依赖空结果锁保护新增。写事务使用 READ COMMITTED，避免不同店铺首次建价目时，空范围间隙锁相互阻塞；父行锁和唯一键仍保护同服务重复新增。锁后使用当前读复核权限、服务类型、规则内容和版本；每次写入后及返回前再次检查会话有效期，等待过久时整批回滚。读取使用只读 RR 事务取得一致快照。

后续报价/订单事务需要协调锁顺序、校验当前规则版本与金额并冻结快照，届时补齐验收。本任务不宣称已具备报价或订单存量保护。操作与实际验证见 [价目验收](../merchant-print-prices.md)。
