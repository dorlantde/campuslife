# ADR-0047：公开商家分类首页的等价查询优化

- 日期：2026-10-28；状态：在用户授权的M01.2“按场景采纳或保留并复测”任务内已实施、验证。无新增业务规则或基础设施。[报告](../reports/public-shop-list-adoption-2026-10-28.md)、[复现方法](../public-shop-list-adoption.md)。

## 问题与选择

原查询联表核对公开资格后排序分页；M01.1显示部分分类查询处理大量匹配才能取首页，限制半连接候选有收益，但无分类/小数据有回退。不能直接将SQL事务耗时视作整个HTTP收益，也不能全局套优化提示。

最终仅在categoryId非空、按现有规则规范化的keyword为空、page=1时调用静态@Select方法categoryFirstPage；size仍为原1～100。使用既有ix_shop_approval_category_id，固定批准状态和分类后按id读取，EXISTS完整验证ACTIVE OWNER及ACTIVE/MERCHANT账号，LIMIT之后回表读取展示列及分类，外层仍ORDER BY id。NO_SEMIJOIN(@eligibility)只作用于命名资格子查询块，以保留有序扫描和提前结束的计划。不是LIMIT后才检查账号资格。

唯一OWNER及分类外键保持EXISTS与原JOIN基数一致。停业店铺、分类停用、名称/评分/openNow等原规则不变；count、未分类列表、有效关键词搜索、后续页及详情仍使用原查询。全响应仍为同一个短只读RR快照，非空列表四条SQL、空页两条，无写入或业务锁。未增加索引、迁移、接口、依赖或XML。

## 验证与取舍

先预验分类与未分类两个首页候选，再独立实例验证实际静态SQL；最终只采纳分类分支。两阶段各覆盖1,000/10,000店、60%/90%/10%资格分布、两个分类及未分类、首页20/100和深页，3,888个正式HTTP样本；整个data响应、独立期待值、特殊关键词/大偏移及真实RR并发检查通过。正式阶段保留原版作为同入口成对对照。

大档原60%分布下，完整HTTP理发首页20条p50为29.09→17.45 ms，打印25.19→13.10 ms；小档低资格且size100基本无益，约0.06～0.07 ms轻微回退。未分类优化未采纳，名称/深页也保留；不增加按total或实时耗时切换SQL的复杂策略。资格极稀疏仍需扫描，count成本未消失，hint需在MySQL升级或数据分布明显变化后重新验证。

定向回归325项零失败/错误/跳过，包含目录/评价、预约/打印整链、OpenAPI/MySQL基础及普通/Web；mysql JAR启动及各自临时实例清理通过。没有重跑全部历史IT，热读延迟不代表并发吞吐或线上容量。源码摘要、逐轮样本及实际ANALYZE树见报告JSON。
