# ADR-0056 私有S3对象存储与LOCAL历史共存

日期：2026-11-02。状态：**用户已采用[方案](../object-storage-design.md)，A/B/C已验证，M04收口。** [B报告](../reports/s3-file-chain-2026-11-02.md)：918项不同相关检查分轮通过，文件LOCAL/S3路由、事务外IO、原引用保护、永久墓碑和V24已落地；真实MySQL＋S3、V23升级及JAR启动通过。默认LOCAL/S3关闭，75操作/32表，无真实文件迁移；SDK从B开始进入生产包。A的71项协议/LOCAL证据及当时115生产依赖边界保留在[A报告](../reports/s3-compatibility-2026-11-02.md)。 C结果见[110项恢复验收](../reports/s3-recovery-2026-11-02.md)及[指南](../s3-recovery.md)：隔离恢复/迁移通过，真实搬迁仍另行授权。

## 选择与取舍

- 本机单节点SeaweedFS私有S3＋AWS SDK for Java 2.x同步客户端；A查证并固定镜像digest与SDK补丁，先实测认证、基础IO、校验和及重启。兼容假设不成立时停止报告，不静默换产品。
- 默认LOCAL，新上传显式选择后端，旧文件按完整存储定位路由并保留本地根。S3故障不自动回退另存，变更新上传目标不改变存量定位。
- 原后端鉴权代理下载、PDF/大小限制、文件引用期限、事务与单实例互斥保持；不直传、不公开对象URL、不把IO放进SQL事务，不借接入S3声称应用支持多实例。
- V24已扩展存储CHECK及巡检索引，当前75操作/V24/32表。UPLOADING/AVAILABLE/DELETING/DELETED原状态保持；未知PUT晚到由可追踪墓碑循环核对，不依赖一次DELETE/超时推断已永久结束。
- 历史LOCAL默认共存，隔离数据上预演迁移；实际文件搬迁Apply、源数据删除、公网部署均需另行明确授权。当前不读取用户持久上传目录或开发凭据。

## 分批与停止条件

1. **A隔离兼容底座**：专用容器/卷/网络/凭据，独立测试源码和依赖，不接业务路径、不迁移DB；通过安全、20MiB字节/hash、精确删除、SDK行为、重启及资源回收后交付。
2. **B文件链与存量兼容（已验证）**：最小LOCAL/S3路由、共享互斥、V24、上传/下载/首次下单/清理和墓碑，真实MySQL与原业务保护验证，918项检查分轮通过。
3. **C故障与恢复（已验证）**：执行真JVM及受控迟到IO、DB＋完整存储备份恢复、隔离迁移预演；补Swagger点击验收，收口到M06，不扩大分布式组件或文件功能。

本批批准的方案无需重复询问；每次只推进路线图当前一个可验收批次。实际结果、失败与兼容差异必须记录，不把测试探针或批准状态标成业务集成完成。

## A验证后的技术约束

已知长度PUT采用path-style及关闭chunked编码，保留校验和；标识只读权限使用已测试的窄Actions＋Deny后缀桶策略组合，不能改为整桶授权。桶列表无权限是200空数组，跨前缀/其它管理仍403。Docker本机专用bridge仅发布回环S3端口，实际Args/生效Ports与标签必须校验；SDK不继承代理/默认凭据链。失败与原因见A报告，B沿这些已验证约束落地，不改变业务规则或实际迁移授权边界。
