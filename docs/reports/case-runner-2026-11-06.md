## 改动与用途

新增 `scripts/case_runner.py`，提供 prepare/start/status/fetch：固定输入副本、摘要和一次性启动标记；独立会话监督进程不依赖 SSH stdio；以原 case 查询未知结果，不补启动。开始时固定总截止并预留清理，按进程出生身份和 pidfd 精确终止本轮会话，回执原子持久发布。任务与清理分别记账，清理失败覆盖绿色结果。

另新增一个无业务合成任务和 16 项 Linux 集成检查。它们只创建 Python 进程和私有临时工作区。未改业务 Java、DDL、pom、前端、既有部署/测量入口、正式 JAR/镜像；未创建业务账号、订单、资金、文件或券记录。没有启动本机 Docker，也未在 ECS 启动业务容器。
